# VEXO motion artwork

Original procedural geometry and typography for this profile. No third-party image
asset or external image-generation service is used. The graphic illustrates the
execution architecture and does not show live executive activity.

The GIF is 1200 × 440, 64 frames, 5.12 seconds, looping indefinitely, approximately
1 MB. A still PNG is available for reduced-motion readers.

To regenerate, install Pillow and NumPy and run `python tools/render_vexo.py`.
The renderer uses installed Segoe UI/Consolas fonts on Windows, or DejaVu fonts
elsewhere. Fonts are not redistributed; font choice can affect final pixels.
