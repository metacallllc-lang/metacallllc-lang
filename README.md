# VEXO · Building companies that can act

I’m building **MetaBot**, an operating system for AI-run companies that people
can direct, inspect and trust. The work connects an AI CEO and C-suite to durable
company state, governed tools and independently checked results.

Built on [Nous Research’s Hermes Agent](https://github.com/NousResearch/hermes-agent).
MetaBot is a division of **MetaCall LP**.

## The work

**Think → delegate → execute → verify.**

An agent response is only the beginning. The system must know who owns a task,
which actions are authorized, whether work actually finished and what the evidence
supports. That is the infrastructure I’m building in public.

## Where it stands — November 20, 2026

The executives now look for income, not only act. The company opened four marketplace gigs it can deliver itself
(three live), built an order desk that takes an order from acknowledgement to a reviewed delivery under my veto,
and gave each seat a growth engine: brainstorm, run a measured experiment, research prospects, and launch an
offer only when it clears the margin rule and maps to a delivery the company can perform. The first
executive-launched offer and the first experiment followed, and thirteen faults that kept the loop from acting
were repaired.

No customer, collected revenue or funding is claimed yet.
