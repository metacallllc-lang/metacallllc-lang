# VEXO · Building companies that can act

I’m building **MetaBot**, an operating system for AI-run companies that people
can direct, inspect and trust. The work connects an AI CEO and C-suite to durable
company state, governed tools and independently checked results.

Built on [Nous Research’s Hermes Agent](https://github.com/NousResearch/hermes-agent).
MetaBot is a division of **MetaCall LP**.

## The work

**Think → delegate → execute → verify.**

An agent response is only the beginning. The system must know who owns a task,
which actions are authorized, whether work actually finished and what the evidence
supports. That is the infrastructure I’m building in public.

## Where it stands — November 16, 2026

<a href="https://github.com/metacallllc-lang/hermes-autonomous-company">
  <img src="https://github.com/metacallllc-lang/hermes-autonomous-company/raw/main/assets/command-center-overview-2026-11-16.jpg" alt="Hermes Command Center on November 16, the company's read-only operations dashboard (financial tiles and email content blurred)" width="100%">
</a>

The executives now act. Each seat has governed tools for the outcomes it owns: internal actions run at once, and
external ones (email, marketplace replies, publishing, invoices) post a veto notice with the full message, then
run after 60 minutes unless I veto. On November 16 two executive-written emails went out, four posts were
published and the CFO read the bank of record. Five faults that kept the loop from acting were found and repaired.

No customer, collected revenue or funding is claimed yet, and neither email has a reply.
[Read the action-authority evidence](https://github.com/metacallllc-lang/hermes-autonomous-company/blob/main/evidence/CSUITE_ACTION_AUTHORITY_2026-11-16.md).
